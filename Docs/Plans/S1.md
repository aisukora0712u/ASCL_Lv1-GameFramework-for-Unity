# S1 · 模块基础与内容基础

## 阶段目标

建立模块共同遵守的身份、内容、执行与恢复规则。

## 依赖与执行顺序

阶段主线先完成 S0；每个目标的实际依赖以目标文件为准。依赖满足只表示可以安排，不代表已开始。S6 按项目独立安排，暂缓专项不计入正式阶段完成率。

## 交付内容

- 模块宿主和上下文
- 稳定定义与内容指纹
- 生命周期/时间/随机及保存契约
- 诊断和验证入口

## 退出条件

- 最小模块组合独立运行，启动失败能够清理
- 内容错误可定位，重命名和引用可治理
- 设置、保存、运行状态分别管理

独立验收目标 [ASCL-S1-900](../Goals/ASCL-S1-900.md) 覆盖本阶段所有正式功能目标。

## 验证与风险边界

复用目标中的验收场景。记录输入、运行环境、工具命令、实际结果、证据与未验证限制。桌面通过后再补平台证据；后端能力、资源所有权和外部副作用不得静默降级。
