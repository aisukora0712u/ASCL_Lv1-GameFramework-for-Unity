# S0 · 基础修整与关键可行性验证

## 阶段目标

建立可恢复、可重演、可定位差异的最小可信基础。

## 依赖与执行顺序

此阶段是主线入口。依赖满足只表示可以安排，不代表已开始。S6 按项目独立安排，暂缓专项不计入正式阶段完成率。

## 交付内容

- 身份和任务终态修整
- 最小移动/射击/伤害模拟
- 后端能力与再分发条件决策记录

## 退出条件

- 跨世界句柄不能误解析，清理等待任务有明确终态
- Unity 桌面与 .NET 相同输入的状态可比较、恢复和重演
- 后端路径满足正式回滚、主机/独服及依赖要求；失败调整路径而非删除目标

独立验收目标 [ASCL-S0-900](../Goals/ASCL-S0-900.md) 覆盖本阶段所有正式功能目标。

## 验证与风险边界

复用目标中的验收场景。记录输入、运行环境、工具命令、实际结果、证据与未验证限制。桌面通过后再补平台证据；后端能力、资源所有权和外部副作用不得静默降级。
