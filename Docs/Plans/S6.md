# S6 · 项目驱动扩展与平台验证

## 阶段目标

按真实项目需求逐项扩展，分开管理暂缓专项。

## 依赖与执行顺序

基础入口为 S1；各项目驱动能力按目标列出的实际前置目标推进，不要求等所有示例完成；每个目标的实际依赖以目标文件为准。依赖满足只表示可以安排，不代表已开始。S6 按项目独立安排，暂缓专项不计入正式阶段完成率。

## 交付内容

- 叙事成长、高级 AI 和世界内容
- 平台、Mod、编辑器与模板
- 2D 适配、IL2CPP 与移动端证据

## 退出条件

- 被安排的模块都有规则核心、示例、测试与支持矩阵
- 未落地项目驱动方向不伪装为已承诺工期
- 暂缓专项不阻塞正式回滚主线

S6 是开放的项目驱动目录，没有预先承诺的总完工时间；目标被实际安排为 committed 后进入实施分母。首次安排时新增阶段退出验收目标；后续扩大范围时更新其依赖并重新安排验收，保留旧验收记录。

## 验证与风险边界

复用目标中的验收场景。记录输入、运行环境、工具命令、实际结果、证据与未验证限制。桌面通过后再补平台证据；后端能力、资源所有权和外部副作用不得静默降级。
