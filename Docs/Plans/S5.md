# S5 · 经营建造示例

## 阶段目标

验证持续世界、资源流转与时间规则。

## 依赖与执行顺序

阶段主线先完成 S4；每个目标的实际依赖以目标文件为准。依赖满足只表示可以安排，不代表已开始。S6 按项目独立安排，暂缓专项不计入正式阶段完成率。

## 交付内容

- 建造、仓储、生产和物流
- 暂停/倍速/离线结算
- 内容升级和存档迁移

## 退出条件

- 资源账可核对，失败或取消不复制/丢失资源
- 离线收益不重复领取
- 迁移失败或缺 Mod 时原档保持可恢复

独立验收目标 [ASCL-S5-900](../Goals/ASCL-S5-900.md) 覆盖本阶段所有正式功能目标。

## 验证与风险边界

复用目标中的验收场景。记录输入、运行环境、工具命令、实际结果、证据与未验证限制。桌面通过后再补平台证据；后端能力、资源所有权和外部副作用不得静默降级。

阶段状态由目标文件计算，此文件不保存手工进度。
