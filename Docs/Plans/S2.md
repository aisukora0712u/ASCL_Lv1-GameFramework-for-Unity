# S2 · 俯视角射击：单机与本地多人

## 阶段目标

完成 3D 平面运动的可玩合作射击主例。

## 依赖与执行顺序

阶段主线先完成 S1；每个目标的实际依赖以目标文件为准。依赖满足只表示可以安排，不代表已开始。S6 按项目独立安排，暂缓专项不计入正式阶段完成率。

## 交付内容

- 资源与场景流程
- 输入席位、表现、音画与 HUD
- 射线及投射物武器、敌人和波次
- 本地多人和输入记录

## 退出条件

- 启动到结算退出完整可运行，支持重复进入
- 至少验证射线命中和飞行投射物两条路径
- 多席位归属正确，退出后任务/订阅/资源恢复预期水平

独立验收目标 [ASCL-S2-900](../Goals/ASCL-S2-900.md) 覆盖本阶段所有正式功能目标。

## 验证与风险边界

复用目标中的验收场景。记录输入、运行环境、工具命令、实际结果、证据与未验证限制。桌面通过后再补平台证据；后端能力、资源所有权和外部副作用不得静默降级。
