# S3 · 射击联机、预测与回滚

## 阶段目标

完成正式 2–8 人合作、混合席位与最小对抗验证。

## 依赖与执行顺序

阶段主线先完成 S2；每个目标的实际依赖以目标文件为准。依赖满足只表示可以安排，不代表已开始。S6 按项目独立安排，暂缓专项不计入正式阶段完成率。

## 交付内容

- 主机及 .NET 独服入口
- 预测/快照/重演/纠正
- 重连和内容一致性
- 坏网诊断及对抗补偿场景

## 退出条件

- 坏网恢复一致状态，重连不重复生成玩家或结算
- 重演音画反馈不重复提交，输入和奖励去重
- 2–8 人通过正式验收；16 人仅记录扩展测量

独立验收目标 [ASCL-S3-900](../Goals/ASCL-S3-900.md) 覆盖本阶段所有正式功能目标。

## 验证与风险边界

复用目标中的验收场景。记录输入、运行环境、工具命令、实际结果、证据与未验证限制。桌面通过后再补平台证据；后端能力、资源所有权和外部副作用不得静默降级。
