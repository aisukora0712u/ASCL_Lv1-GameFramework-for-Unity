# ASCL-S6-038 · 2D 规则复用与表现碰撞适配

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过2D 规则复用与表现碰撞适配沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D06-C01 输入动作层**：移动、瞄准、交互语义；重绑定、上下文切换与设备变化。
- **D07-C01 逻辑与表现桥接**：逻辑实体可有零个或多个视图；支持生成、隐藏、替换和销毁。
- **D08-C04 碰撞契约**：2D/3D 分别适配，回滚实现声明形状、查询、更新与确定性范围。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

2D 输入/视图/碰撞适配，保持 .NET 规则隔离。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。
