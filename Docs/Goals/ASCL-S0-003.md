# ASCL-S0-003 · 最小确定性射击模拟与快照探针

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过最小确定性射击模拟与快照探针沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D02-C06 多时间域**：区分现实、游戏、固定 Tick 和 UI 时间，规定暂停、倍速和权威时间指令。
- **D02-C07 可恢复随机流**：固定算法版本，捕获恢复内部状态；独立随机流、随机调用顺序和重演验证。
- **D08-C03 受控运动**：用显式状态与指令描述移动、速度、阻挡和滑动。
- **D08-C04 碰撞契约**：2D/3D 分别适配，回滚实现声明形状、查询、更新与确定性范围。
- **D14-C07 预测与回滚**：输入历史、恢复、重演、权威纠正和逐 Tick 差异定位，是正式目标。
- **D16-C03 快照比较**：定位首次分歧的 Tick、实体和字段。

仅使用有限碰撞形状与平面受控运动验证正式回滚可行路径；不承诺复杂刚体确定性，不把原型当作完整联机。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

最小 Tick、指令、状态快照、随机流和模拟身份契约；对当前 float/System.Random 路径先测量再确定隔离的模拟数值策略。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

- [ ] Unity 桌面/.NET 同输入逐 Tick 比较
