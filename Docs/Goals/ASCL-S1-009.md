# ASCL-S1-009 · 本地诊断、因果追踪与故障入口

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过本地诊断、因果追踪与故障入口沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D16-C01 运行时检查器**：查看世界、实体、组件、订阅、任务、计时器和资源租约。
- **D16-C02 因果追踪**：从输入、Action、数值、Buff 追踪到表现事件。
- **D16-C04 本地问题报告**：手动导出版本、配置、日志、输入及必要快照。
- **D16-C08 自动化入口**：CLI/Editor 命令具备预检查、结构化结果和可恢复编辑。
- **D16-C11 故障注入**：可重复的加载失败、断网、取消、乱序和损坏存档。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

检查器、事件关联身份、报告导出和只读/受管工具入口；默认不连接远程遥测。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 能追踪输入到规则事件的因果链
- [ ] 导出最小复现资料
- [ ] CLI 输出结构化结果
- [ ] 加载失败和取消可重复注入。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

能追踪输入到规则事件的因果链；导出最小复现资料；CLI 输出结构化结果；加载失败和取消可重复注入。

提供正常路径与相关失败、取消、重复和恢复路径的可重复样例。先 .NET/Unity 桌面，IL2CPP/移动端在对应目标验证。
