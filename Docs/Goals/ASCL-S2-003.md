# ASCL-S2-003 · 多人 UI 与基础绑定

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过多人 UI 与基础绑定沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D06-C04 多玩家 UI**：独立焦点、菜单权、HUD，支持共享视图和分屏。
- **D06-C05 UI 基础增强**：补 UI 绑定生成器、列表虚拟化、模态框、导航历史与工具提示。
- **D06-C06 提示与红点**：从业务状态派生提示，明确订阅、去重和释放。
- **D16-C07 源码生成**：显式系统注册、UI 绑定、定义访问、协议和快照辅助按需增加。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

协议与快照生成分别由 ASCL-S3-001、ASCL-S3-004 承接；本目标只交付 UI 绑定部分。

## 公共接口与兼容

扩展 uGUI 路由、绑定生成器、提示订阅与席位 UI 上下文。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 独立 UI 焦点不会抢占其他席位
- [ ] 共享视图/分屏 HUD 归属正确
- [ ] 绑定释放与列表复用无旧订阅。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

独立 UI 焦点不会抢占其他席位；共享视图/分屏 HUD 归属正确；绑定释放与列表复用无旧订阅。

提供正常路径与相关失败、取消、重复和恢复路径的可重复样例。先 .NET/Unity 桌面，IL2CPP/移动端在对应目标验证。
