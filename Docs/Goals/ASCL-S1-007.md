# ASCL-S1-007 · 设置与玩家档案隔离

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过设置与玩家档案隔离沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D04-C01 用户与设备设置**：分别管理音频、显示、输入、语言、辅助功能；加载存档不回退最新设置。
- **D04-C02 玩家档案**：多个角色或档案、选择、进度摘要；与设备设置区分。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

用户/设备设置与玩家档案存储边界；保持现有保存容器可复用。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 加载旧档不回退音量/键位
- [ ] 不同档案状态隔离
- [ ] 切换失败不损坏当前档案。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

加载旧档不回退音量/键位；不同档案状态隔离；切换失败不损坏当前档案。

提供正常路径与相关失败、取消、重复和恢复路径的可重复样例。先 .NET/Unity 桌面，IL2CPP/移动端在对应目标验证。
