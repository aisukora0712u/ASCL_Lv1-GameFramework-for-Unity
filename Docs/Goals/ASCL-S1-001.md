# ASCL-S1-001 · 模块装配、上下文与应用流程

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过模块装配、上下文与应用流程沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D01-C01 模块描述与依赖**：声明必需和可选依赖、运行环境；检查缺失依赖、循环与能力要求。
- **D01-C02 启动与关闭编排**：按依赖顺序初始化，失败清理已启动模块，逆序关闭并等待异步释放。
- **D01-C03 应用流程**：组合启动、内容检查、菜单、加载、游戏中、结算与退出流程。
- **D01-C04 运行上下文**：应用、世界、会话、场景和玩家席位使用明确作用域与服务所有权。
- **D01-C05 能力查询**：报告后端重连、取消、快照等真实能力，不静默降级。
- **D01-C06 模块诊断**：查看状态、依赖、启动耗时、关闭失败原因。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

模块描述、宿主、启动停止、上下文与能力查询；保留显式/生成注册，不引入强制全局反射服务定位器。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。
