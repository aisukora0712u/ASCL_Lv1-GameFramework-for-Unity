# ASCL-S0-004 · 网络后端与免费再分发可行性决策

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过网络后端与免费再分发可行性决策沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D01-C05 能力查询**：报告后端重连、取消、快照等真实能力，不静默降级。
- **D14-C01 传输适配**：连接、可靠性、顺序、通道、预算与断开原因。
- **D14-C07 预测与回滚**：输入历史、恢复、重演、权威纠正和逐 Tick 差异定位，是正式目标。
- **D14-C10 专用服务器入口**：纯 C# 规则在 .NET 无引擎环境运行，可选部署。

选择可行实现路径；验证失败继续寻找满足正式目标的路径。免费可分发不等于运营免费，不预先指定付费后端。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

网络能力描述必须区分插值、预测、回滚、命中补偿；不支持不能静默降级。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。
