# ASCL-S2-004 · 逻辑视图桥接、挂点与池化

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过逻辑视图桥接、挂点与池化沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D07-C01 逻辑与表现桥接**：逻辑实体可有零个或多个视图；支持生成、隐藏、替换和销毁。
- **D07-C02 挂点与附着**：武器、头顶 UI、特效跟随；声明附着物释放规则。
- **D07-C03 表现生成与池化**：按资源和使用场景复用视图，与逻辑生命周期配合。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

逻辑句柄到视图租约的桥接与所有权协议；不把 GameObject 作为规则实体身份。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 零视图逻辑实体能运行
- [ ] 一实体多视图可独立替换
- [ ] 回收武器/头顶 UI 后不残留附着引用。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

零视图逻辑实体能运行；一实体多视图可独立替换；回收武器/头顶 UI 后不残留附着引用。

提供正常路径与相关失败、取消、重复和恢复路径的可重复样例。先 .NET/Unity 桌面，IL2CPP/移动端在对应目标验证。
