# ASCL-S1-002 · 稳定定义 ID、目录与引用图

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过稳定定义 ID、目录与引用图沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D02-C02 稳定定义 ID 工具**：生成 ID、查重、重命名保护、废弃记录和旧引用迁移；保留现有 int/string 的渐进兼容。
- **D03-C02 定义目录**：稳定检索技能、Buff、物品、敌人、建筑和任务定义。
- **D03-C04 内容引用图**：反向查找引用者，预览删除、重命名与替换的影响。
- **D16-C06 内容检查器**：查重复 ID、悬空引用、循环、缺资源和构建遗漏。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

类型化定义引用包装与目录访问，兼容现有 int/string 表示。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 定义重命名保持身份
- [ ] 重复、废弃复用和悬空引用被检测
- [ ] 反向引用定位到来源并有迁移例子。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

定义重命名保持身份；重复、废弃复用和悬空引用被检测；反向引用定位到来源并有迁移例子。
