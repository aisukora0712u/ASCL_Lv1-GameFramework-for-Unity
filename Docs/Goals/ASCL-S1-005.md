# ASCL-S1-005 · 配置导入、内容指纹与 Mod 清单基础

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过配置导入、内容指纹与 Mod 清单基础沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D03-C01 配置表导入**：类型、枚举、范围、跨表引用验证；生成只读运行数据。
- **D03-C06 内容版本与指纹**：规范化生成内容及 Mod 依赖顺序；统一构建、存档和会话内容识别。
- **D15-C06 Mod 清单**：身份、版本、依赖、顺序和支持版本；数据与资源 Mod。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

只读定义产物、内容清单和版本契约；每类内容只有一个编辑源。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 类型/范围/跨表错误阻止生成
- [ ] 相同规范化内容生成相同指纹
- [ ] Mod 顺序或玩法变化影响指纹，平台资源变体分开记录。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

类型/范围/跨表错误阻止生成；相同规范化内容生成相同指纹；Mod 顺序或玩法变化影响指纹，平台资源变体分开记录。

提供正常路径与相关失败、取消、重复和恢复路径的可重复样例。先 .NET/Unity 桌面，IL2CPP/移动端在对应目标验证。
