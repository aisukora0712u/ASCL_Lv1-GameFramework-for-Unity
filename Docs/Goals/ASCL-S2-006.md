# ASCL-S2-006 · 动画与可取消反馈组合

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过动画与可取消反馈组合沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D07-C06 动画适配**：规则状态映射动画，明确动作中断与结束通知边界。
- **D07-C07 反馈组合**：组合音效、特效、跳字与震动，支持取消和所有权清理。
- **D07-C08 回滚反馈管理**：预测事件有稳定身份；确认、撤销或去重，防止重演重复副作用。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

逻辑事件与表现事件分层；动画回调不能未经记录修改回滚状态。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 反馈能取消/释放
- [ ] 动作中断不提交过期结束结果
- [ ] 相同事件身份不会重复播放，保留预测确认入口。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

反馈能取消/释放；动作中断不提交过期结束结果；相同事件身份不会重复播放，保留预测确认入口。

提供正常路径与相关失败、取消、重复和恢复路径的可重复样例。先 .NET/Unity 桌面，IL2CPP/移动端在对应目标验证。
