# ASCL-S4-003 · 指令预览、撤销与复盘

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过指令预览、撤销与复盘沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D11-C03 指令系统**：合法性、目标、结果、记录、确认和重演。
- **D11-C04 行动预览**：移动范围、伤害预估和可达目标。
- **D11-C07 指令撤销**：仅对声明支持的本地操作提供，不承诺任意操作可逆。
- **D11-C08 战斗复盘**：按阶段查看输入指令与结算。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

可验证指令、结果及可逆能力，限制撤销范围。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 预览不修改权威状态
- [ ] 声明可撤销的本地指令能恢复
- [ ] 记录重演后结果一致
- [ ] 复盘定位到指令和结算。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

预览不修改权威状态；声明可撤销的本地指令能恢复；记录重演后结果一致；复盘定位到指令和结算。

提供正常路径与相关失败、取消、重复和恢复路径的可重复样例。先 .NET/Unity 桌面，IL2CPP/移动端在对应目标验证。
