# ASCL-S3-001 · 网络传输与协议适配

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过网络传输与协议适配沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D16-C07 源码生成**：按本目标需要增加协议/快照辅助生成，复用显式注册工具。

- **D14-C01 传输适配**：连接、可靠性、顺序、通道、预算与断开原因。
- **D14-C02 协议与消息**：版本、序列、请求响应及重复消息识别。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

传输能力、消息信封、序列与请求响应契约；使用 S0 选定路径。

遵循 PLAN.md 的身份、生命周期、模拟、内容版本与后端能力边界。稳定接口破坏性变更提供迁移路径；未测试平台不标为支持。

## 验收条件

- [ ] 可靠/不可靠与顺序语义可观察
- [ ] 版本不兼容清晰拒绝
- [ ] 超时、重复、乱序消息不产生重复执行。
- [ ] 交付与验证证据已写入元数据 evidence，实际验证记录写入 log。

## 验证场景

可靠/不可靠与顺序语义可观察；版本不兼容清晰拒绝；超时、重复、乱序消息不产生重复执行。

提供正常路径与相关失败、取消、重复和恢复路径的可重复样例。先 .NET/Unity 桌面，IL2CPP/移动端在对应目标验证。
