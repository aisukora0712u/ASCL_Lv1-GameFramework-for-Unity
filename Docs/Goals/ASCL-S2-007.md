# ASCL-S2-007 · 空间查询、受控碰撞与导航

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过空间查询、受控碰撞与导航沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D08-C01 通用空间查询**：附近、范围、距离、方向、阵营过滤。
- **D08-C02 空间索引**：按几十至数百对象测量选择数据结构，不预先承诺万级规模。
- **D08-C03 受控运动**：用显式状态与指令描述移动、速度、阻挡和滑动。
- **D08-C04 碰撞契约**：2D/3D 分别适配，回滚实现声明形状、查询、更新与确定性范围。
- **D08-C05 导航适配**：路径请求、跟随、动态障碍和取消；异步结果经有效运行上下文提交。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

空间查询、受控运动状态、碰撞后端与导航请求接口。
