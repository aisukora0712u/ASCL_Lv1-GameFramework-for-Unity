# ASCL-S3-008 · 坏网测试与网络性能报告

## 问题与预期收益

当前基线尚未完成本目标的正式验收。通过坏网测试与网络性能报告沉淀可跨项目复用、可观察和可验证的能力。

## 工作内容与边界

- **D14-C11 网络诊断**：延迟、丢包、重演次数、纠正幅度、消息量和带宽。
- **D16-C03 快照比较**：定位首次分歧的 Tick、实体和字段。
- **D16-C05 性能基线**：记录热路径分配、池峰值、加载、保存与重演成本及环境。
- **D16-C11 故障注入**：可重复的加载失败、断网、取消、乱序和损坏存档。

只实现本目标列明能力并提供最小完整示例；跨模块需求通过显式依赖接入，不提前实施其他目标。

## 交付物

- 可安装或可组合的规则实现／适配，以及最小完整使用示例。
- 与目标相符的验证结果、支持矩阵、错误诊断和必要迁移说明。

## 公共接口与兼容

故障注入配置、快照差异与本地报告；只声明测过的环境和规模。
